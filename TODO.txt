  SECTION 4 — BALL DETECTION (Pi: ball_detector.py)
────────────────────────────────────────────────────────────────────────────────

[DEPLOY]   Connect a USB camera to /dev/video0 on the Pi.
           Aim it at the floor/intake zone to see incoming fuel balls.

[TUNE]     HSV_LOW / HSV_HIGH
           These MUST be set for your ball colour before detection works.
           Method:
             1. Point camera at a ball under field lighting.
             2. Capture a frame (use the :1182 MJPEG stream).
             3. Sample the HSV values at the ball's centre pixel.
             4. Set LOW = (hue-15, sat-40, val-40), HIGH = (hue+15, 255, 255).
             5. Iterate until the mask cleanly covers balls and rejects field.
           File: pi/ball_detector.py

[CONFIRM]  BALL_DIAMETER_INCHES = 9.5

           File: pi/ball_detector.py

[TUNE]     CAMERA_HFOV_DEG = 68.5

           File: pi/ball_detector.py

[TUNE]     MIN_BALL_AREA = 200 (px²)

[DEPLOY]   Drive the robot over the bump while logging the following NT keys

             AbsoluteEncoders / Accel Z Raw (g)
             AbsoluteEncoders / Accel Z Filtered (g)
             SmartDashboard/limelight-front / IMU Pitch (deg)
             SmartDashboard/limelight-front / IMU Accel Z (g)
             SmartDashboard/limelight-rear  / IMU Pitch (deg)
             SmartDashboard/limelight-rear  / IMU Accel Z (g)
           Record peak values on each sensor to calibrate thresholds below.

[TUNE]     kAccelFilterAlpha = 0.15  (Constants.BumpDetectionConstants)
           Low-pass filter alpha for Pigeon 2 X/Y/Z axes.
           Live-tunable via BumpTuner NT keys.
           Lower = heavier smoothing; higher = faster response.
           Start at 0.15; raise toward 0.3 if filtered signal lags raw.
           File: Constants.java

[TUNE]     kBumpPitchThresholdDegrees = 8.0  (Constants.BumpDetectionConstants)
           Pitch angle above which the Pigeon 2 alone flags a bump.
           Live-tunable via BumpTuner NT keys.
           Set to ~70% of peak pitch observed during bump traversal.
           File: Constants.java

[TUNE]     kBumpAccelZDeviationThreshold = 0.25  (Constants.BumpDetectionConstants)
           Deviation from 1 g on Pigeon 2 Z-axis that flags a bump.
           Live-tunable via BumpTuner NT keys.
           Set to ~60% of peak deviation observed during bump traversal.
           File: Constants.java

[TUNE]     kLimelightAccelZDeviationThreshold = 0.25  (Constants.BumpDetectionConstants)
           Same threshold applied to both front and rear Limelight accel Z.
           Live-tunable via BumpTuner NT keys.
           Tune independently from kBumpAccelZDeviationThreshold if the
           Limelight IMU reports different magnitudes than the Pigeon 2.
           File: Constants.java
