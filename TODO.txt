── Bump Detection & Vision Stability ───────────────────────────────────────────
  NOTE: All bump thresholds are read from Constants.java. Edit and redeploy.

[DEPLOY]   Drive the robot over the bump while logging the following NT keys
           in Elastic / AdvantageScope before tuning any thresholds:
             Swerve/Accel/ZRaw_g
             Swerve/Accel/ZFilt_g
             SmartDashboard/limelight-front / IMU Pitch (deg)
             SmartDashboard/limelight-front / IMU Accel Z (g)
             SmartDashboard/limelight-rear  / IMU Pitch (deg)
             SmartDashboard/limelight-rear  / IMU Accel Z (g)
           Record peak values on each sensor to calibrate thresholds below.

[TUNE]     kAccelFilterAlpha = 0.15
           Low-pass filter alpha for Pigeon 2 X/Y/Z axes.
           Lower = heavier smoothing; higher = faster response.
           Edit: Constants.java → BumpDetectionConstants.kAccelFilterAlpha

[TUNE]     kBumpPitchThresholdDegrees = 8.0
           Pitch angle above which the Pigeon 2 alone flags a bump.
           Set to ~70% of peak pitch observed during bump traversal.
           Edit: Constants.java → BumpDetectionConstants.kBumpPitchThresholdDegrees

[TUNE]     kBumpAccelZDeviationThreshold = 0.25
           Deviation from 1 g on Pigeon 2 Z-axis that flags a bump.
           Set to ~60% of peak deviation observed during bump traversal.
           Edit: Constants.java → BumpDetectionConstants.kBumpAccelZDeviationThreshold

[TUNE]     kLimelightAccelZDeviationThreshold = 0.25
           Same threshold applied to both front and rear Limelight accel Z.
           Tune independently if Limelight IMU differs from Pigeon 2 magnitude.
           Edit: Constants.java → BumpDetectionConstants.kLimelightAccelZDeviationThreshold

[CONFIRM]  After tuning bump thresholds, verify in Elastic that:
             • Vision/Active Source shows the correct camera.
             • The bump flag does NOT trigger during normal fast driving.
             • The bump flag DOES trigger reliably within one loop cycle.
           If false positives occur during aggressive turns/acceleration,
           raise thresholds in Constants.java and redeploy.

[TUNE]     kBumpVisionStdDevMultiplier = 10.0
           Applied to the winning Limelight's stddevs when a bump is confirmed.
           If the pose still drifts mid-bump, raise it (e.g. 25–50).
           If vision recovers too slowly after the bump, lower it.
           Edit: Constants.java → BumpDetectionConstants.kBumpVisionStdDevMultiplier

[TUNE]     Limelight standard deviations (Limelight.java)
           Currently hardcoded to VecBuilder.fill(0.1, 0.1, 10.0) for both
           cameras. Test at match-representative ranges and compare front vs.
           rear pose outputs to Pigeon odometry. Tighten x/y if accurate;
           loosen if it jerks the pose on tag loss.

── Ball Detection  ───────────────────────────────────────────────────────────────
  REQUIRES Pi — currently permanently disabled. Skip.

[TUNE]     HSV_LOW / HSV_HIGH
           Must be set for your ball colour before detection works.
           Method:
             1. Point camera at a ball under field lighting.
             2. Capture a frame (use the :1182 MJPEG stream).
             3. Sample the HSV values at the ball's centre pixel.
             4. Set LOW = (hue-15, sat-40, val-40), HIGH = (hue+15, 255, 255).
             5. Iterate until the mask cleanly covers balls and rejects field.
           File: pi/ball_detector.py

[TUNE]     CAMERA_HFOV_DEG = 68.5
           Check your camera's datasheet for horizontal field-of-view.
           Affects the angle and distance estimates for nearest ball.
           File: pi/ball_detector.py

[TUNE]     MIN_BALL_AREA = 200 (px²)
           Raise if you get false detections on field markings or game
           elements; lower if balls are missed when far from the camera.
           File: pi/ball_detector.py

[TUNE]     camera.setExposureManual(50)
           Adjust for your venue lighting. Lower values reduce motion blur
           at the cost of a darker image.
           File: pi/ball_detector.py
